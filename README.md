# ADAS Pedestrian AEB Project

## Description
This project implements a vision-based Advanced Driver Assistance System (ADAS) 
for pedestrian safety using deep learning, temporal risk prediction, and 
confidence-aware Automatic Emergency Braking (AEB) logic.

## Folder Structure
- configs/          : configuration files
- data/raw/         : raw datasets (not committed)
- data/processed/   : processed datasets
- src/              : source code
- notebooks/        : experiments and debugging notebooks
- results/          : outputs, metrics, logs
- reports/          : documentation and paper drafts

## Workflow
- Each member works on their own branch
- No direct commits to main
- Pull requests require review
